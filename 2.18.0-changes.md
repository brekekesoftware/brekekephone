# Brekeke Phone 2.18.0 — what is new and what changed since 2.17.22

This list shows what a user or an admin will notice. Each row says how the app worked in 2.17.22 (Before),
how it works in 2.18.0 (After), and a simple way to try it. Row ids (S1-1, …) are for comments and test cases.

"Admin" rows are things a phone system admin sets up; users only see the result.

A sign-in link is a link the admin sends to a user. Tapping it opens the app and signs in.

## Not in 2.18.0

- An "encrypted sign-in link" was built during 2.18 and then removed. It is not in this version.
- A TURN server built into the app (used by the old "TURN" setting) is removed. The app now uses only the phone system's TURN server.

## Notes for PM (spec vs app)

- The spec says the link can set a TURN server, its type, user and password. The app does not do this: the link can only turn TURN on or off (S1-6, S2-1).
- The spec lists TURN SERVER, TURN TRANSPORT, TURN USERNAME and TURN PASSWORD in the account settings. The app has only "USE TURN AUTOMATICALLY" (S2-1).
- The spec says a "Set a password" button. The app shows it as a hint in the password box (S1-5).
- "Mailed links now include uc=1" is a phone system change, not an app change.
- Not in the spec: S1-7, S6-3, S6-4, S6-5, S7-2 to S7-6, S8-3 to S8-6, S11-1 to S11-4, S12-2 to S12-6.
