# Brekeke Phone 2.18.0 — changes since 2.17.22

- Before = 2.17.22, commit `7070e1bc` (2026-09-07, tip of `2.17.21-fix-google-play-policy-issues`).
- After = 2.18.0, commit `82428974` (2026-11-09, branch `2.18-upgrade-android-api-level-35-to-36`, which includes master).
- How rows were picked: all 165 commits after 2.17.21 (`9520a7f0`) were checked. Fixes already shipped in 2.17.22,
  reverted work, logs, docs, build tools and library updates with no visible change were left out.
  When several commits changed one behavior, only the final behavior is described, read from the 2.18.0 code.
- Row ids (S1-1, …) are for PM comments and QA test cases.
- `⚠ spec outdated` = the code differs from `2.18-spec.md`. `(not in spec)` = a change the spec does not list.

| S1-2 | All      | Not available                                                                                                                            | Refused hash on a new account: the app adds no account and shows "This link has expired. | S1-3 | All      | Not available                                                                                                                            | Existing account, different hash: the saved hash is replaced and the app signs in again. | S1-4 | All      | A link with a password for an existing account did not replace a wrong saved password.                                                   | A link with a new plain password replaces the saved one and signs in again.                                                                                                                                                                                                                      | Save a wrong password, open a link with the right one: sign-in succeeds.                                                |
| S1-5 | All      | Not available                                                                                                                            | Account form of a hash account: the PASSWORD field is empty and not required, shows the hint "Set a password" and the text "Signed in by link". ⚠ spec outdated                                                                                                                                  | Open the edit page of a hash account: hint and text shown; saving without a password works.                             |
| S1-6 | All      | Not available                                                                                                                            | New fields: `turn` = 0/false or 1/true sets "USE TURN AUTOMATICALLY" (see S2-1); `uc` = 1/true or 0/false turns UC on or off; `parks` = `701:Sales,702:Support` sets park numbers and names, `parks=` clears all. A missing field keeps the saved value; a bad value is ignored. ⚠ spec outdated | Open links with each field; check the account form. Open a link without them: values stay.                              |
| S1-7 | All      | A link or call push for an existing user with a different phone index did not move the live registration to the new phone. (not in spec) | The app reconnects with the new phone index and stops push for the old phone id.                                                                                                                                                                                                                 | Signed in as phone 1, open a link with `phone_idx=2`: calls ring on phone 2's id, not phone 1's.                        |

Spec note for S1-6: the spec still lists `turn=host:port`, `turn_transport`, `turn_user`, `turn_pass`.
The 2.18.0 code reads only `turn=0/1`; the other TURN fields are ignored.
Spec note for S1-5: the spec says a "Set a password" button; the code shows it as a hint inside the PASSWORD field.
Spec line "Mailed links (from the PBX) now include uc=1": no app change; this is a PBX-side item.

## 2. TURN (account form)

| #    | Platform | Before (2.17.22)                                                                                                              | After (2.18.0)                                                                                                                                                            | How to check                                                                                                                                  |

Spec note: section 2 lists TURN SERVER, TURN TRANSPORT, TURN USERNAME, TURN PASSWORD and "replaces the PBX TURN".
The 2.18.0 form has only the one switch.
